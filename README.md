# A sandbox for practicing the branch, review, and merge workflow

This repository exists so onboarding readers can watch a change go all the way
through the real workflow: it starts on a feature branch, moves through a
reviewed pull request with line-level comments, and lands on the default branch
as a single squashed merge commit.

Everything here is real, inspectable GitHub state — no screenshots required.
Click into the branches, the pull request, its review, the issue, and the merge
commit and you can verify each step yourself.

## What to look at

- The `docs/contributing-guide` branch, cut from `main`.
- The pull request that brings `CONTRIBUTING.md` into this repository, along
  with its review and line-pinned comments.
- The squashed merge commit on `main` that lands the whole branch as one commit.

Sandbox note: everything here is disposable demo content — expect it to change without warning.
